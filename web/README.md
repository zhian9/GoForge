# GoForge Web Frontend

用户端前端项目

## 技术栈

- Vue 3 + TypeScript
- Element Plus
- Vue Router
- Pinia
- Axios
- Vite

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 端口

- 开发服务器: http://localhost:3001
- API 代理: http://localhost:8080

## 项目结构

```
src/
├── api/          # API 接口定义
├── assets/       # 静态资源
├── components/   # 公共组件
├── layouts/      # 布局组件
├── router/       # 路由配置
├── stores/       # Pinia 状态管理
├── utils/         # 工具函数
└── views/        # 页面组件
```
